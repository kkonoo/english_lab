# 🎧 잉글리시 랩

원어민 말은 표현을 이미 알아야 들려요. 그래서 구동사를 **실제로 들리는 소리**로 먼저 익히는 영어회화 공부 앱이에요.

주소: https://kkonoo.github.io/english_lab/

## 기능

| 탭 | 하는 일 |
|---|---|
| 오늘 | 구동사·표현·단어를 섞은 복습 + 새 카드(하루 10개 기본, 종류별로 번갈아 필수부터). 소리 듣고 → 정답 보고 → 다시 / 헷갈려요 / 알아요. 말투 사다리는 "이 말을 격식으로 하면?" 식으로 나와요 |
| 구동사 → 격자 | 핵심동사 × 불변사 표. 원 색 = 진도, 원 크기 = 빈도(필수만 보기 가능). 불변사 핵심 이미지, 열·행 퀴즈 |
| 구동사 → 목록 | 구동사 335개(일상 288 + 💼 업무·연구 47) 검색(영어·뜻·한글 소리), 진도·빈도·⭐ 필터 |
| 표현 | 하고 싶은 말별 32그룹 · 705개(관용구·제안 응답·요즘 구어·매너 한마디·약어). 🎩격식/🙂무난/👟캐주얼/⚠️주의 표시와 필터. 📝 내 표현(들은 표현 적어 두기·목록 복사). 글자 뜻 → 실제 뜻 → 왜 그런지, 예문·소리. 그룹·전체 퀴즈(보기는 다른 그룹에서) |
| 단어 | 🪜 말투 사다리 30세트(친구 → 동료 → 업무 메일) · 부사 110 · 형용사 190(강도 사다리) · 동사 200. 💼 격식·업무 단어 120개 포함. 뉘앙스·강세·말투 |
| 🔍 검색 | 구동사·표현·단어·쉐도잉 문장을 한 번에 (Ctrl+K) |
| 📝 | 들은 표현 적어 두기 — 앱에 이미 있으면 바로 알려 줌 |
| 쉐도잉 | 상황별 10세트 + 문법별 10세트(240문장). 듣기(보통·천천히) → 🎙 녹음 → 원문과 번갈아 듣기 → 🗣 발음 확인(음성 인식, 크롬 권장). 세트마다 참고 영상 링크 |
| 쉐도잉 → 소리 규칙 | 굴리는 t, 이어 붙이기, 사라지는 소리, 약해지는 기능어, 삼키는 t, 불변사 강세 + 해당 카드 모음 |

카드 한 장에는 구동사 · 빈도 · 실제 들리는 덩어리와 한글 소리(예: figure it out → 피겨리라웃) · 적용된 소리 규칙 · 뜻 1~7개(한 달에 한 번 이상 들을 뜻마다 예문) · 예문과 번역 · 팁이 들어 있어요. 예문은 모두 이 앱용으로 새로 쓴 거예요.

## 처음 쓸 때

1. 주소를 열고 **오늘 → 시작하기**를 눌러요.
2. 🔊 소리를 듣고 무슨 구동사인지 떠올린 뒤 **정답 보기**(Space)를 눌러요.
3. 다시(1) / 헷갈려요(2) / 알아요(3)로 채점하면 다음 복습 날짜가 정해져요 (1 → 3 → 7 → 14 → 30일).
4. 이미 아는 건 격자나 목록에서 카드를 열고 **이미 알아요**를 눌러 건너뛰어요.
5. 휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 쓸 수 있어요.

⚙️ 설정에서 하루 새 카드 수, 오늘 탭에 섞을 종류, 카드 앞면(소리 / 구동사 / 뜻), 읽어주기 속도·목소리, 글씨 크기, 테마를 바꿀 수 있어요.

## 데이터는 어디에

- 공부 기록은 이 기기 브라우저의 IndexedDB(`english_lab`)에 저장돼요. 안 되면 localStorage(`english_lab-db`)를 써요.
- 쉐도잉 녹음은 이 기기의 IndexedDB(`english_lab-rec`)에만 저장돼요(동기화 안 함, 문장마다 마지막 녹음 하나).
- 테마·글씨 크기·마지막 탭은 localStorage `english_lab-prefs`.
- 설정 → 데이터에서 **백업 파일 저장 / 불러오기**로 기기를 옮길 수 있어요.
- 오른쪽 위 **로그인**(Google)을 하면 Firestore에 동기화돼요.
  - `users/{uid}/progress/{카드 id}`: 카드마다 문서 하나 (`box, due, lapses, seen, t`). 두 기기에서 같은 카드를 고치면 나중에 고친 쪽이 이겨요.
  - `users/{uid}/meta/state`: 설정·즐겨찾기·날짜별 공부량·쉐도잉 진도·참고 영상 링크·내 표현(항목마다 나중에 바뀐 쪽 우선). 공부량은 날짜별로 큰 값을 남겨요.
  - 규칙은 `firestore.rules` (내 기록은 나만 읽고 쓰기).
- `js/firebase-config.js`가 `null`이면 로그인 버튼이 숨고 이 기기에만 저장돼요.

- 구동사 데이터는 `data/phrasals.js`, 불변사·소리 규칙은 `data/core.js`.

### Firebase 연결 (처음 한 번)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들어요.
2. **Authentication → 로그인 방법 → Google** 사용 설정, **설정 → 승인된 도메인**에 `kkonoo.github.io` 추가.
3. **Firestore Database** 만들기 → **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 게시.
4. **프로젝트 설정 → 내 앱 → 웹 앱 추가** → 나온 `firebaseConfig`를 `js/firebase-config.js`에 붙여 넣기.

## 개발

```
powershell -File tools/serve.ps1     # http://localhost:8767/
```

빌드 없이 파일만 고치면 돼요. js/css 파일을 새로 만들면 `sw.js`의 `SHELL`과 `index.html` 스크립트 순서에 추가해요.
